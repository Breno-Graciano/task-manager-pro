# 💼 Task Manager Pro

Gerenciador de tarefas robusto via terminal, desenvolvido em Python com foco em **Clean Code** e **Persistência de Dados**.

## 🛠️ Tecnologias e Conceitos
- **Python 3**: Linguagem base.
- **JSON**: Armazenamento de dados (simulando um banco de dados).
- **POO (Programação Orientada a Objetos)**: Organização de classes.
- **Modularização**: Separação de responsabilidades (Lógica, Armazenamento e Interface).
